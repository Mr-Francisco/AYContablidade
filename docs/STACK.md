# Stack Tecnológica

## Frontend

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Biblioteca:** React 19
- **Linguagem:** TypeScript 5.x
- **Estilização:** Tailwind CSS 4
- **Componentes UI:** Radix UI
- **Animações:** Framer Motion
- **Visualização de Dados:** Recharts
- **Mapas:** Leaflet
- **Gestão de Dados:** SWR
- **ORM Auxiliar:** Prisma


## Backend

- **Linguagem:** Python 3.12
- **Framework:** FastAPI
- **ORM:** SQLAlchemy 2.x
- **Migrações:** Alembic
- **Validação e Schemas:** Pydantic 2.x
- **Autenticação:** JWT (PyJWT)
- **Rate Limiting:** SlowAPI


## Inteligência Artificial e Serviços

- **Integração IA:** API OpenAI (modelo mais recente disponível)
- **Finalidade:** Sistema de perguntas e respostas baseado nos dados da aplicação


## Infraestrutura

- **Base de Dados:** PostgreSQL 18.x
- **Containerização:** Docker + Docker Compose
