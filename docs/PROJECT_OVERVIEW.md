# Visão Geral do Projeto

O **AYContabilidade** é um ERP de Contabilidade em migração de um sistema Piloto (HTML/CSS/JS + Local Storage) para uma arquitetura moderna e escalável. O objetivo é modernizar a stack tecnológica sem perder as funcionalidades de negócio existentes.

## Objetivos da Migração

- Preservar integralmente as funcionalidades, regras de negócio, fluxos e comportamentos do Piloto.
- Migrar a interface para React/Next.js com design premium.
- Substituir a camada de persistência (Local Storage) por PostgreSQL.
- Criar uma API robusta e segura em FastAPI.
- Manter a interface em Português (Portugal).
